## 🎯 Problème résolu

Les minoteries et huileries burkinabèses gèrent leur production sur papier. Pas de traçabilité des lots, pas de suivi des pannes, pas d'analyse des rendements. Résultat : pertes invisibles, qualité inconsistante, zéro données pour négocier avec les acheteurs.

## 💡 Solution

MillTrack digitalise la chaîne de production :
- Suivi des lots d'entrée (matière première) → sortie (produit fini)
- Monitoring des machines et alertes pannes
- Calcul des rendements de transformation
- Traçabilité pour certification export

## 🎯 Cible

Minoteries (blé, maïs), huileries (sésame, karité, arachide) — Burkina Faso et CEDEAO.

## 🖥️ Fonctionnalités prévues

| Module | Description |
|--------|-------------|
| Lots | Réception matière première, pesée, qualité |
| Production | Suivi process, durée, rendement |
| Machines | Maintenance préventive, alertes pannes |
| Stocks | Inventaire intrants et produits finis |
| Rapports | Analyse rendements, export PDF/Excel |
| Certifications | Documents qualité pour export |

## 🛠️ Stack

- Next.js 15 (App Router) + TypeScript + Tailwind CSS
- Supabase (PostgreSQL + Realtime)
- shadcn/ui + Framer Motion + Recharts
- Vercel
